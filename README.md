# ロボットシステム学課題1_素因数分解コマンド

## 概要
入力した数値を素数に分解するコマンドです。
![test](https://github.com/hiroto20060205-oss/robosys2025.git)

## 使用方法

### リポジトリのクローン

```bash
git clone https://github.com/hiroto20060205-oss/robosys2025.git
cd robosys2025
```

### 実行コマンド

- **このコマンドで実行** `./prime factorization.py`

## 動作環境
- Ubuntu 24.04.3 LTS

## 必要なソフトウェア
- **python**
    - テスト済みバージョン:3.7 ~ 3.13
